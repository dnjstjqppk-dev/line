# 🎨 MESSENGER UX/UI AUDIT REPORT

## 1. LINE 고유 디자인 시스템 감사 및 구현 명세

카카오톡 스타일을 배제하고 오리지널 LINE 고유의 브랜드 언어와 시각적 문법을 엄격히 적용하였습니다.

| UI 컴포넌트 | LINE 전용 디자인 사양 | 구현 상세 |
|---|---|---|
| **메인 컬러** | `#06C755` (Primary LINE Green), `#05b34c` (Hover) | 카카오 노란색 일체 배제, 글로벌 LINE 산뜻한 에메랄드 그린 적용 |
| **대화방 배경** | `#849ebf` ~ `#9bbad8` (Soft Chat Slate Blue) | 전 세계 사용자에게 친숙한 LINE 시그니처 소프트 슬레이트 블루 |
| **수신 말풍선** | 좌측 화이트 버블 + 좌측 꼬리표 + 아바타 + 이름 | 라운드 코너 버블과 정교한 좌측 꼬리표(CSS triangular clip-path) |
| **발신 말풍선** | 우측 LINE Green 버블 + 우측 꼬리표 + 읽음 인디케이터 | 직관적인 `읽음` 텍스트 상태 및 발송 시각 배치 |
| **3단 분할 레이아웃** | 68px 독 + 320px 리스트 패널 + 메인 워크스페이스 | 데스크톱 메신저 표준 레이아웃 완성 |
| **하버 액션 트레이** | 6종 리액션 이모티콘 + 답장 + Keep + 공지 + 복사 + 취소 | 마우스 호버 시 부드러운 플로팅 트레이 노출 |
| **통화 오버레이** | 펄스 링 애니메이션, 타이머, 마이크/카메라 토글 | 통화 수신/발신 시 직관적인 모달 오버레이 제공 |
| **스티커 트레이** | Brown, Sally, Emotion, Daily 탭 및 원클릭 전송 | 하단 작곡기(Composer) 내 통합 스티커 선택창 제공 |
| **대화방 서랍** | 릴레이 노트, 일정 캘린더, 공유 사진첩 | 우측 슬라이드형 대화방 보조 패널 완성 |
